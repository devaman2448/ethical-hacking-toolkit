Password Strength Checker 🔐

A simple Python program that checks how strong a password is.

About

This project checks a password based on its length and the characters it contains. It tells the user whether the password is Weak, Moderate, or Strong.

Features

- Checks password length.
- Checks uppercase letters.
- Checks lowercase letters.
- Checks numbers.
- Checks special characters.
- Displays password strength.

Requirements

- Python 3
- Kali Linux or any system with Python installed.

How to Run

Clone the repository:

git clone https://github.com/devaman2448/ethical-hacking-toolkit.git

Open the project folder:

cd ethical-hacking-toolkit

Run the program:

python3 password_checker.py

Example Output

Enter password: Hello123!
Password strength: Strong
